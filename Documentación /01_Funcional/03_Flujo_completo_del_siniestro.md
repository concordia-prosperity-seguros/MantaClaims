# Flujo completo del siniestro

## 1. Recepción
RGC envía el siniestro y la documentación asociada.

El sistema debe registrar:
- Identificador del siniestro.
- Información de póliza.
- Información recibida del TPA.
- Documentos originales.
- Fecha y hora de recepción.
- Estado inicial.

## 2. Análisis de IA
La IA ejecuta las mismas cuatro fases que ejecutaría un analista.

## 3. Resultado de IA
Existen dos situaciones:
- La IA completa el análisis.
- La IA marca revisión humana.

La revisión humana debe ocurrir cuando la IA no tiene información suficiente o encuentra una situación que requiere decisión humana.

Una inconsistencia detectada por la IA no implica por sí misma que el caso deba pasar a revisión humana si la información disponible permite concluir el análisis. La IA debe completar el análisis cuando tenga evidencia suficiente para tomar el resultado correspondiente.

## 4. Revisión humana
El caso entra a la bandeja de revisión humana.

El analista:
- Visualiza el punto donde quedó la IA.
- Revisa el resultado previo.
- Continúa desde esa fase.
- Completa el análisis.
- Registra inconsistencias.
- Registra glosas.
- Genera una recomendación.

## 5. Decisión del director
El director revisa el caso completo y decide:
- Pagar el valor reconocido.
- Pagar parcialmente y glosar el saldo.
- No pagar.

## 6. Ejecución
Cuando existe un pago:
- Se genera el proceso de indemnización.
- Se conecta con el ERP para generar la nota crédito.
- Se registra el movimiento en el sistema actuarial.

## 7. Cierre
El caso queda cerrado con:
- Documentación original.
- Resultado de IA.
- Análisis humano, cuando exista.
- Glosas.
- Evidencias.
- Decisión.
- Pago.
- Movimientos.
- Historial completo.

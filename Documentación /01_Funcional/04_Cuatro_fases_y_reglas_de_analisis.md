# Cuatro fases y reglas de análisis

## Fase 1. Validación inicial del siniestro
Se valida que el caso recibido tenga la información necesaria para iniciar el análisis y que corresponda a una póliza y siniestro identificables.

## Fase 2. Validación documental y médica
Se compara lo facturado con la atención reportada.

Fuentes mencionadas:
- Facturas.
- Soportes
- Historia clínica.
- Epicrisis.
- Interconsultas
- RIP.
- Terapias.
- Otros soportes entregados por el TPA.

Pregunta funcional central:
¿Existe soporte médico que justifique el servicio facturado para ese siniestro?

Si no existe soporte suficiente, el valor se considera inconsistente.

## Fase 3. Validación del valor
Se revisa si el valor cobrado por el prestador corresponde con los valores reconocibles según las referencias aplicables y el manual tarifario.

Ejemplos de inconsistencia:
- El procedimiento facturado no corresponde con lo reportado médicamente.
- El valor cobrado supera el valor reconocible.
- El procedimiento facturado no tiene correspondencia en el manual tarifario.

La existencia de una inconsistencia debe quedar explicada.

## Fase 4. Validación del amparo
Se verifica:
- Amparo aplicable.
- Disponibilidad del amparo.
- Tope.
- Valor facturado.
- Valor consistente.
- Valor reconocible.
- Valor a pagar.

Ejemplo:
Si el amparo tiene $12.000.000 disponibles y el prestador reporta $10.800.000 para el siniestro, el valor está dentro del tope. Si las validaciones previas son consistentes, corresponde reconocer el valor aplicable.

Si el valor reconocido supera el disponible, el pago queda limitado al valor disponible del amparo.

## Regla general
La coherencia del servicio facturado con la historia clínica no significa que todo el valor deba pagarse. El análisis pasa por las cuatro fases. Un servicio puede ser médicamente consistente y aun así tener un valor no reconocible o exceder el amparo disponible.

# Matriz de evidencia y trazabilidad

Cada decisión debe poder relacionarse con:

| Elemento | Evidencia esperada |
| Siniestro | Información original recibida |
| Servicio | Documento médico y factura |
| Valor | Factura y referencia tarifaria |
| Amparo | Información de póliza |
| Glosa | Evidencia y comentario |
| Resultado IA | Resultado y fase |
| Revisión humana | Usuario, fecha y análisis |
| Decisión director | Decisión y soporte |
| Pago | Registro de pago y nota crédito |

La matriz debe convertirse en criterio de aceptación para auditoría.

# Estados, inconsistencias y glosas

## Estado consistente
Se utiliza cuando la información revisada:
- Tiene soporte suficiente.
- Corresponde con la atención reportada.
- Cumple las reglas tarifarias aplicables.
- Corresponde con el amparo.
- Respeta el tope disponible.

## Estado inconsistente
Se utiliza cuando existe una razón para no reconocer total o parcialmente el valor.

Ejemplos:
- No existe validación médica que soporte el servicio.
- La factura no corresponde con la historia clínica.
- El procedimiento no corresponde con lo reportado.
- El valor facturado supera el valor reconocible.
- El procedimiento no tiene correspondencia en el manual tarifario.
- El valor excede el amparo disponible.
- Falta documentación necesaria para soportar el reconocimiento.

## Estado por verificar
Se decidió no utilizar un estado separado. Cuando un elemento no puede reconocerse por falta de soporte o aclaración, se registra como inconsistente y se deja el comentario que explica la causa.

## Glosa
La glosa representa el valor que no se reconoce.

Debe conservar:
- Valor.
- Motivo.
- Evidencia.
- Documento relacionado.
- Fase donde fue detectada.
- Usuario.
- Fecha y hora.

El prestador puede responder frente a la glosa.

## Decisión del director
El director revisa lo consistente y lo glosado y determina:
- Qué se paga.
- Qué se glosa.
- Si no se paga el caso completo.

La glosa no debe quedar como un dato aislado. Debe estar conectada con la evidencia y con la decisión final.

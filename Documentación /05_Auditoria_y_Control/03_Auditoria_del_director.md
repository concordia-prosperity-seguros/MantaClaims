# Auditoría del director

La auditoría debe permitir al director consultar:

- Documentación original.
- Resultado de IA.
- Fases completadas.
- Motivo de revisión humana.
- Acciones del analista.
- Inconsistencias.
- Glosas.
- Comentarios.
- Decisiones anteriores.
- Decisión final.
- Pago.

El director tiene acceso a esta pestaña. El analista no.

La auditoría debe servir para revisar si las decisiones tomadas estuvieron soportadas y fueron coherentes con las reglas aplicables.

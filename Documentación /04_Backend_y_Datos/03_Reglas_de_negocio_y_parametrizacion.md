# Reglas de negocio y parametrización

## Reglas identificadas
1. Un servicio debe tener soporte para ser reconocido.
2. El valor debe corresponder con la referencia tarifaria aplicable.
3. El procedimiento debe tener correspondencia con el manual tarifario.
4. El gasto debe corresponder al siniestro.
5. El gasto debe corresponder al amparo aplicable.
6. El pago no debe superar el disponible del amparo.
7. Una inconsistencia debe tener explicación.
8. Una glosa debe tener evidencia.
9. El director toma la decisión final.
10. Las decisiones anteriores se conservan.
